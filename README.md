[Geckolib](https://github.com/bernie-g/geckolib)

### Note On Geckolib
This library includes geckolib bundled into its jar, this means you do not need to include it for my mods.
Fabric will load only one geckolib so there wont be any issues on a bundled mod conflicting with the standalone mod.
